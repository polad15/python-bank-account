# Python Bank Account

A simple bank account project written in Python for practicing object-oriented programming (OOP).

## Features

* Create a bank account
* Deposit money
* Withdraw money
* Check account balance
* Input validation with `try/except`

## Technologies

* Python
* Object-Oriented Programming (OOP)

## Usage

Run the program:

```bash
python Bank_account.py
```

Follow the menu and choose an option from 1 to 4.
